# midi-music
This project explores simple MIDI-based music generation using Python and Markov chains.

## What I did
- Loaded MIDI files using pretty_midi
- Extracted pitch sequences
- Built a simple Markov chain model
- Generated new MIDI melodies
- Compared flute and piano MIDI data

## Observations
- Flute MIDI often produces more coherent melodies
- Piano MIDI is harder because of polyphonic structure
- Simple Markov models tend to sound repetitive

## Tools
- Python
- pretty_midi
- Jupyter Notebook
